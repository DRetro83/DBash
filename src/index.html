[ TIMESHIFT ]

Use the ⟲ BACKUP box at the bottom, like the WEB box: tick it before you change something = DBash makes a Timeshift backup. Everything OK? Untick it = the backup is deleted. Not OK? ⟲ ROLL BACK. Your files in /home are never touched.

[ SUDO ]

You type it in the terminal itself, like in Konsole. It is only kept in memory, never saved.

[ COMMAND SAFETY ]

SAFE read-only · SUDO changes the system (tick ⟲ BACKUP first to be able to undo) · DANGER always extra confirmation.
WEB Commands from answers that used web search are marked and always need confirmation. Web pages can hide instructions for the AI, so DBash never runs them blindly.

[ WEBSITES ]

Reader mode (show pages as text inside DBash)
Off = websites only open in your normal browser. On = you can choose: ≡ READER MODE or ↗ OPEN IN BROWSER.

[ AI ROLE ]

How the AI helps you. Your Notes for the AI (above) are always added on top of the role.
What the AI gets with every question: 1. DBash rules (always: safety, RUN, sudo, file cards) 2. AI role (the choice above) 3. Your system (OS, disks, current folder) 4. Your notes (Notes for the AI: they change the role) 5. Language (the language you write in, else English)
